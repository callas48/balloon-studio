# Windows 설치형 다음 단계

2026-10-25. 현재 결과는 로컬에서 실행 가능한 웹 편집기 소스다. Windows 설치 프로그램은 아직 만들지 않았다.

## 공유할 코드

`public/`의 편집기·폰트·이미지·문서 형식과 Undo 경로를 웹·모바일·Windows에서 공유한다. 별도 편집기를 다시 만들지 않는다. 현재 `node scripts/dev-local.mjs`로 Windows에서도 실행할 수 있다.

## 구현 순서

1. Electron 실행 진입점과 패키징 설정을 별도 추가한다. Node 통합을 끄고 contextIsolation과 sandbox를 켠다. 창은 앱에 포함한 로컬 편집기만 열고 외부 탐색은 시스템 브라우저로 보낸다.
2. 프로젝트 열기/다른 이름으로 저장과 저장 경로 기억을 먼저 연결한다. 파일 접근은 최소한의 IPC API로 제한하고 임의 경로 읽기 API를 renderer에 노출하지 않는다. 기존 브라우저 다운로드/업로드는 유지한다.
3. 앱 전용 데이터 경로에 저장하고 기존 브라우저 IndexedDB가 자동 이전된다고 설명하지 않는다. 프로젝트 내보내기/가져오기로 이동을 지원한다.
4. Windows 설치 파일을 빌드하고 새 PC의 설치·실행·재시작·한글 경로·프로젝트 저장/복원·폰트·PNG 출력을 확인한다. 코드 서명과 업데이트 배포는 그 뒤 별도 구성한다.

## 구현 전 확인할 제한

로컬 공용 에셋 API는 빈 목록이고 방문 통계는 수집하지 않는다. 기존 서비스의 DB·스토리지·로그인 정보는 이 저장소에 포함되지 않는다. 실제 PSD 및 편집용 PNG 기능은 별도 진행 중인 작업과 합칠 때 해당 테스트와 파일 호환을 확인한다. 설치형·자동 업데이트·네이티브 파일 저장이 완료됐다고 보고하지 않는다.
