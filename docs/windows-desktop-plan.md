# Windows 설치형 설계

갱신: 2026-10-25. 아래는 사용자와 합의한 구현 요구사항이다. 현재 Electron 실행 진입점·설치 프로그램·업데이터는 아직 구현하지 않았다.

## 공유할 코드와 오프라인 동작

public/의 편집기·폰트·이미지·문서 형식과 Undo 경로를 웹·모바일·Windows에서 공유한다. 앱 실행과 기본 편집은 인터넷·로그인·업데이트 서버 응답에 의존하지 않는다. 포함된 말풍선·폰트·에셋은 설치 파일에 넣고 로컬에서 읽는다. 사용자가 로컬에 보관한 프로젝트와 이미지의 열기·편집·저장·PNG 출력은 오프라인에서도 유지한다. 기존 브라우저의 IndexedDB는 자동 이전되지 않으며 프로젝트 내보내기/가져오기로 옮긴다.

## 합의한 업데이트 흐름

- 설치형은 Electron + NSIS + electron-updater를 기본안으로 준비한다. 첫 설치 파일부터 업데이트 경로를 포함한다. 배포 주소·접근 방식·코드 서명은 첫 배포 전에 확정한다.
- 실행 시 작은 버전 정보만 조회한다. 편집기 시작은 조회 완료를 기다리지 않는다. 설정에 수동 업데이트 확인을 제공한다.
- 최신 버전이 있으면 현재/새 버전·변경 사항과 업데이트 버튼을 표시한다. 자동 다운로드·강제 재시작은 하지 않는다. 사용자가 누르면 다운로드와 검증을 시작한다.
- 차등 다운로드를 우선한다. 파일별 직접 덮어쓰기 대신 설치 패키지의 블록 대조를 이용해 변경분을 받는다. 압축·패키징 때문에 변경량보다 다운로드량이 커질 수 있으므로 실제 구버전→신버전의 전송량을 측정한다. 변경되지 않은 대용량 폰트·에셋을 재사용하기 좋은 패키징을 검토한다.
- 차등 다운로드에 필요한 캐시가 없거나 차등 전송이 실패하면 전체 다운로드 필요와 용량을 안내하고 사용자가 선택하게 한다. 라이브러리의 자동 전체 다운로드 fallback을 그대로 두어 이 요구를 우회하지 않도록 실제 제어 경로를 검증한다.
- 다운로드·무결성 검증을 마친 뒤 작업 저장 성공을 확인하고 설치·재시작한다. 저장 실패 시 종료하지 않는다. 프로그램 설치 경로와 사용자 프로젝트/자동저장/내 에셋 경로는 분리하고 업데이트가 사용자 작업을 지우지 않게 한다.

## 오프라인에서는 알림 없이 사용

- 자동 확인 중 인터넷 미연결·DNS 오류·시간 초과·업데이트 서버 장애는 조용히 처리한다. 팝업·토스트·OS 알림·반복 경고를 띄우거나 편집을 막지 않는다. 오프라인에서 이전에 확인한 업데이트 안내도 자동으로 띄우지 않는다.
- 온라인 판정 하나만 신뢰하지 않고 실제 요청 실패도 같은 원칙으로 처리한다. 요청 시간 제한과 재시도 간격을 두어 반복 요청·UI 지연을 막는다. 연결이 돌아오면 이후 정상 확인 시점에 다시 조회한다.
- 사용자가 수동 확인을 누른 경우에만 해당 설정 화면에 연결 상태를 짧게 표시할 수 있다. 네트워크 오류 알람이나 재시도 팝업은 띄우지 않는다.
- 오프라인 실행에 만료된 업데이트 확인이나 최신 버전 설치를 강제하지 않는다.

## 구현 순서와 검증

1. Electron 진입점과 패키징 설정을 추가한다. Node 통합을 끄고 contextIsolation과 sandbox를 켠다. 앱에 포함된 편집기만 로드하며 외부 링크는 시스템 브라우저로 보낸다.
2. 프로젝트 열기/다른 이름으로 저장과 저장 경로 기억을 최소 IPC API로 연결한다. 기존 업로드/다운로드 호환 경로를 보존한다.
3. 알림만 하는 버전 확인, 클릭 시 차등 다운로드, 저장 후 설치를 구현한다. 업데이트 상태와 편집기 상태를 분리한다.
4. 실제 구버전 설치 후 신버전 업데이트를 검사한다. 다운로드량·다운로드 중단·해시 불일치·전체 다운로드 선택·저장 실패·재시작 후 문서/폰트/에셋 복원을 확인한다.
5. 네트워크 차단·연결은 있으나 서버 불통·DNS 실패·지연·연결 복구를 각각 검사한다. 자동 알림이 없고 실행/프로젝트 열기/편집/저장/출력이 가능한지 실제 패키징한 앱에서 확인한다. 단위 검사와 실제 Windows 설치 검증을 구분한다.

로컬 공용 에셋 API는 빈 목록이며 방문 통계는 수집하지 않는다. 기존 서비스의 서버 DB·스토리지는 이전되지 않았다. 실제 PSD/편집용 PNG 기능은 별도 진행 작업과 병합할 때 테스트와 호환을 확인한다.
