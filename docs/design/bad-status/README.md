# 범용 상태 시스템과 도트 아이콘

2026-10-18. 사용자 상태창 명세 및 후속 아이콘 지시서 기준.

## 사용 경로
- 게임 → 상태창·프로필 → 범용 상태 시스템에서 상태이상 목록 / 시스템 메시지 추가.
- 기존 에로스탯·도트 RPG 상태창 편집 영역에서도 각각 추가 가능.
- 캔버스 한 번 클릭/탭은 선택·이동, 더블클릭/더블탭은 이름·설명·메시지 빠른 편집. 선택 시 기존 크기8점과 회전 핸들을 공유한다.
- 상태이상 추가/복제 시 내용에 맞춰 높이를 늘린다. 이후 문구가 길어지면 디자인·크기 → 내용에 맞춰 높이 조절을 사용한다.

## 구현 범위
- 목록별 최대32항목. 사용자 이름·설명·직접 입력 분류·분류색·아이콘·단계·지속시간·등급·중첩·효과·해제조건·메시지를 저장한다.
- 단계: 숫자/로마숫자/칸 게이지/별/숨김. 지속시간은 자유 텍스트 및 예시 선택.
- 아이콘: 기본 벡터8종 + 도트12종, 이미지 업로드, 없음. 크기/글자 간격 조절.
- 항목 복제·삭제·위/아래 및 포인터 드래그 정렬. 효과·해제조건도 행 추가/삭제/정렬.
- 목록/아이콘/아이콘+이름/3크기 카드, 선택 상태 상세 영역, 전체 표시 토글.
- RPG/VN/모바일/다크 판타지/SF, 배경색·배경 불투명도·선·모서리·그림자·글자·강조색·여백·간격 조절.
- 상태 데이터에서8종 시스템 메시지 생성. 생성한 메시지는 독립 객체로 수정/변형/숨김 가능하며 이후 원본 상태 변화로 덮어쓰지 않는다.
- 기기 및 프로젝트 내 프리셋 저장(최대20), 적용/삭제/JSON 백업·불러오기. 업로드 아이콘과 디자인·표시옵션 포함. 서버 계정 공유 저장은 아님.
- 예시10개는 사용자가 선택해서 추가한다. 기본 새 항목은 범용 입력용이며 특정 상태를 코드로 강제하지 않는다.
- Undo/Redo와 프로젝트 JSON, 내보내기, 활성·복원 페이지 썸네일에서 공통 렌더/에셋 로드 사용.

## 데이터와 책임
- `items[].kind:'narration'`의 선택 `statusUI.version:1`에 저장. 기존 항목 호환.
- `parentId`는 기존 상태창 편집 메뉴에서 연결 객체를 찾는 용도다. 화면 표시·수명·위치는 독립이며 기존 상태창 삭제 시 자동 삭제하지 않는다.
- `bad-status-data.js`: 스키마/기본값/예시/문구/이미지 로드.
- `bad-status.js`: Canvas 레이아웃·공통 렌더.
- `bad-status-controls.js`: PC·모바일 공통 편집기, 정렬·빠른 편집·프리셋.
- 상태 객체는 말풍선 연결·꼬리·비틀기에서 제외하고 기존 이동·크기·회전·가시성·복제 경로를 사용한다.
- 아이콘 업로드4MB/400만픽셀, 저장 최대256px/40만문자. 상태UI 총24M문자, 프리셋 기기저장12M문자 제한.

## 도트 제작
- 정확한16×16 격자에서 픽셀 단위로 작성한 프로젝트 고유 에셋. 생성 이미지 축소나 기존 상업 게임 아이콘 추출이 아님.
- `scripts/make-bad-status-icons.cjs`가 12종16px/32px PNG, manifest, 원본 픽셀맵과 이름표 시트를 재생성한다. 32px는 nearest-neighbor 정수2배,24px판은 이번 범위에서 제공하지 않는다.
- RGBA 투명 배경, alpha0/255만 사용, 공통1px 어두운 외곽선, 아이콘별3~5색. 신체 관련 항목은 비노골적 곡선·V·방울·반짝임으로 표현.
- `public/bad-status-icons/manifest.json`: 한글명·영문명·팔레트. `pixel-source.json`: 재현 가능한16×16 원본 픽셀맵.
- 렌더에서는 도트 그림의 보간을 끈다. 임의 크기/회전/캔버스 배율에서는 화면상 픽셀 폭이 균일하지 않을 수 있다. 원본PNG와32px판은 정수격자 유지.
- 후속2차15종은 미제작. 이번에 요청한 우선12종만 구현.

## 전체 편집 점검 후 보강
- 접힌 편집 구역 자동 열기와 스크롤, 상세/메시지 표시 토글, 복제ID 재발급과 예전 중복ID 원본 선택 구별, 프리셋 선택 상세 보존, 자동 문구 저장 길이 제한 적용.
- 정렬 도중 포커스 상실·업로드 취소·큰 프리셋 파일 안내 보강.
- `node scripts/check-editor-audit.cjs`로 상태·아이콘·전체 입력행·주요 템플릿 등20개 선별 검사. 테스트 환경의 오래된 경로/빠진 모듈도 복구. 실제 브라우저·휴대폰은 별도 확인 필요.

## 복수 상태 표시
- 상태 목록: 상단 추가 버튼 또는 예시 여러 개 추가 체크박스로 함께 표시. 최대32개.
- 여러 상태로 메시지 만들기: 항목을 체크하고 통합 메시지 생성. 메시지 창에서 직접 상태 추가/목록에서 여러 개 가져오기도 가능.
- 행마다 아이콘·제목·설명을 독립 편집하고 정렬/삭제. 더블클릭/더블탭은 해당 행 입력칸을 연다.
- 선택필드 messageRows/selectedMessage가 없는 기존 파일은 과거 단일 메시지 경로 그대로 사용. 새 다중 행도 공통 렌더·JSON·썸네일·프리셋·복제에 연결.
- 다중 메시지는 최대32행. 생성 후 원본 상태 수정이 메시지를 덮어쓰지 않는다.

## 일반 RPG 메시지 템플릿
- 레벨 업 / HP LOW / MP LOW / 저주받음 / 출혈 / 갑옷 파괴6종, 총 도트 아이콘18종.
- 게임 시스템 메시지 카드로 새 객체를 만들거나, 기존 메시지 편집기의 게임 메시지 템플릿 카드로 현재 창에 추가.
- 빈 메시지는 초기 내용으로 채우며 내용이 있는 창은 새 행으로 추가. 기존 문구를 덮어쓰지 않고 Undo1회,32행 상한·stale/busy 보호를 유지.
- 초기 제목/설명/아이콘/강조색은 사용자가 자유롭게 편집. 별도 게임 계산이나 캐릭터 수치 변경은 하지 않는다.

## 굿/배드 분류와 능력치 변화
- 아이콘과 게임 메시지 선택기에서 전체/굿/배드,공용 아이콘 필터 및 이름 검색. LV/ATK/MAG,한국어 능력치 이름 검색 지원.
- 굿은 레벨업·ATK UP·MAG UP,레벨다운/능력치 감소 등은 배드 기본 분류. 벡터8종은 공용. 사용자 데이터나 캔버스 표시를 필터링하는 기능은 아니다.
- 현재 선택값은 검색/분류에서 제외돼도 유지하고,같은 객체를 편집하는 동안 필터 상태 유지. Undo/프로젝트 JSON에 검색 상태를 섞지 않는다.
- 추가5종: level_down/atk_up/atk_down/mag_up/mag_down. 현재 도트23종·메시지 템플릿11종. 상승 금색 화살표,하락 탁한곤색 화살표. 검=공격력,책=마력.
