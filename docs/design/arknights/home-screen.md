# 명일방주 홈 화면 — Day / Night

- 사용자 제공10번(6569)은 Day, 9번(6570)은 Night로 확정. 이 디렉터리의 원본 참고 이미지 참조. 출처 링크 https://arknights.wiki.gg/wiki/Home_Screen/UI (직접 접근은403, 제공 이미지로 비교).
- `public/arknights-ui.js`, gameui gamePreset:5. 기존 프리셋 번호 유지. 1536×864 가로 장 기본 생성, 기존 장에 추가도 선택 가능. 다른 종횡비에서는16:9 구도를 유지하고 바깥은 투명.
- 편집값을 공유하는 테마2종. Day 밝은 패널/검정 글자, Night 어두운 패널/흰 글자, 모집·상점 청록색 공통. 상단 메뉴·재화/시각, 좌측 레벨·닥터 이름·비서 대사·뉴스, 우측 메뉴·이성·이벤트 배너.
- 배경/투명 캐릭터/우측 배너/좌측 뉴스 4개 이미지 슬롯. 배경 cover 확대·위치, 캐릭터 위치·크기 조절. 스크린샷의 캐릭터/배경/광고를 기본 그림으로 배포하지 않음.
- 각 메뉴 문구·표시, 그룹 표시, 알림 수와 남은 일수 편집. 테마를 바꿔도 이미지/문구/수치 유지. JSON/Undo/출력/페이지 썸네일 공통 Canvas 경로.
- 벡터로 재작성한 첫 버전. 메뉴 기울기/그림자/체스 모티프와 내장 Pretendard의 가로 압축을 사용한다. 원본 아이콘·로고·전용 폰트와 픽셀 단위로 동일한 복원은 아님. 나머지8개 테마는 미구현.
- `tests/arknights-ui.cjs`: 실제 폰트/Canvas, 테마 팔레트와 값 보존·Undo, 메뉴 개별 숨김/문구, 공통 검증/dispatch, 투명 여백, 이미지4종/복제/JSON, 아이콘 구멍의 하부 그림 보존, 업로드 busy/유효성/페이지 변경 방어 검사.
- 실제 브라우저/모바일 기기 미확인. 자동 검사/빌드와 Sites native 배포 상태를 구분해 기록한다.
