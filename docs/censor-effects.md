## 저장과 출력

- `public/censor-effects.js`는 기존 native `kind:asset`, 고정 ID `censor-tape-rect`, `censor-<mosaic|blur|frost>-<rect|circle>`를 등록한다. `censorSettings:{version:1,gap?,strength?,scope?}`를 선택적으로 추가하며 누락 값은 gap=36, strength=55, scope=image다. scope는 image/all 한 열거값이다. 검증에서 범위·형식을 확인한다. 처리된 이미지/원본 복사/Undo 기록을 JSON에 추가하지 않는다.
- `drawReferenceBalloon` 공통 경로로 편집 Canvas·현재 장 썸네일·단일 PNG/JPG/WEBP·프로젝트 PNG ZIP에 같은 효과를 합성한다. 입력 원본은 변경하지 않는다. 임시 Canvas는 한 효과당 524,288픽셀/변 최대 1,024px 이하(모자이크는 올림 여유를 둔 1,000px 기준), 처리 후 1×1로 해제한다. 필터는 alpha를 premultiply해 처리한다. 전체 페이지의 ImageData 복사나 장별 흐림 캐시를 만들지 않는다.
- 현재 Canvas 변환행렬의 역행렬로 표본을 뽑아 회전·축소 썸네일에서도 원본 위치를 맞춘다. 뒤틀기는 효과 영역의 경계에 적용하며 사진 자체를 뒤틀어 옮기지 않는다. 큰 영역은 계산 해상도를 제한하므로 최대 크기에서 질감이 더 거칠어질 수 있다. GPU 내부 복사와 기존 페이지 상주 메모리까지 모두 없애거나 모든 OOM을 예방한다고 보장하지 않는다.
- 경고 띠는 보통 벡터/텍스트로 직접 그린다. 뒤틀기를 켜면 기존 유한 stickerWarpCache의 공통 래스터 경로를 사용한다. 새 무제한 캐시를 만들지 않는다.
- 팝업 입력은 한 제스처 한 Undo와 객체/문서 교체·busy·숨김 가드, opening release 호환 클릭 차단을 유지한다. 입력 렌더는 기존 requestEditorInputRender로 프레임당 합친다. 검열 에셋의 모서리·상하좌우 8개 공통 크기 손잡이는 가로세로를 독립 조절한다. 고정 PNG 판별에서도 censor 메타데이터는 비율 잠금에서 제외한다. 한 축으로만 당기면 다른 축과 반대편 고정점은 유지하며 회전된 로컬 축에서도 동일하다. 일반 고정 PNG의 비율 제한은 유지한다.
