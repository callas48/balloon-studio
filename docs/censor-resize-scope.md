## v257 독립 크기와 기본 에셋 제외

사용자 확인: 모자이크/블러의 X·Y 중 한 축을 바꿔도 두 축이 같은 비율로 커지고, CENSORED 에셋까지 흐려졌다.

`object-rotation.js`의 공통 8개 크기 손잡이는 fixed PNG 에셋을 비율 고정 대상으로 처리하고 있었다. `app.js`의 옛 크기 변경 경로에는 censor 제외가 있었으나 이 실제 공통 핸들러에는 빠져 있었다. `fixedAsset`에서 censor 메타데이터를 제외해 가로·세로가 독립적으로 변한다. 모서리는 X/Y 이동량을 각각 반영하고 변 가운데 손잡이는 해당 축만 바꾼다. 회전한 객체는 로컬 축을 사용하며 반대편 고정점, 한 드래그 한 Undo, 취소·핀치 복원을 보존한다. 일반 fixed PNG와 사진/템플릿의 기존 비율 잠금은 유지한다.

`balloon-groups.js`의 공통 `drawAllBalloons`에서 표시된 native mosaic/blur/frost를 이미지 바탕에 먼저 적용한다. 이어 일반 items(글자·말풍선·CENSORED·다른 에셋·표지판·링)를 원래 상대 순서대로 그린다. 필터끼리도 원래 상대 순서를 유지한다. 문서의 레이어 배열, ID, 저장 데이터와 선택을 재정렬하지 않는다. 연결 말풍선의 그룹 렌더/반투명 합성은 기존 경로를 유지한다. 이 변경은 items 오버레이를 필터에서 제외하는 것이며 사진으로 합쳐진 글자·장식이나 이미지 바탕 안의 구성 요소를 자동 분리하지 않는다.

링의 내부 검열 해제는 문서 목록에서 해당 필터보다 위에 있는 링만 대상으로 하는 규칙을 유지한다. 그림만 모드에서 링 장식 자체는 다른 에셋처럼 필터 뒤에 그려져 선명하다. 전부 모드에서는 위 선택 규칙을 따른다. 새 전체 페이지 사본이나 픽셀 캐시를 만들지 않으며 현재 장 Canvas·썸네일·PNG/JPG/WEBP·PNG ZIP은 모두 같은 합성 순서를 사용한다.
