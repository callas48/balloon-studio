## 링의 모자이크·블러 해제

링 안쪽은 「모자이크·블러 모두 / 모자이크만 / 블러·거친 흐림만 / 사용 안 함」을 선택한다. 해제는 공방에서 올린 native `censor-mosaic/blur/frost` 레이어만 대상으로 한다. 이미 사진 픽셀에 합쳐진 모자이크/블러에서 소실된 원본을 복원하는 기능은 아니다. 단색 가림막·안개·글자·다른 사진은 지우지 않는다.

`drawBackdropCensor`가 그릴 때 현재 필터보다 위에 있는 표시된 링을 찾는다. 필터의 회전을 역변환한 작은 마스크에 링 안쪽 타원/뒤틀린 윤곽과 링 회전을 적용한다. 링의 불투명도를 마스크 alpha로 합치고, 필터 출력의 alpha만 `alpha × (1 − maskAlpha)`로 줄인다. 링 자체는 나중에 띠와 글자만 그린다. 원본을 다시 칠하거나 중간 글자 레이어를 통째로 지우지 않는다.

여러 링은 alpha 합성으로 겹치며 반투명 링은 점진적으로 검열을 해제한다. 링을 숨기거나 불투명도 0으로 하면 구멍이 사라지고, 옮기면 예전 영역은 다시 검열된다. 링보다 위의 필터는 그 링의 내부 해제 대상이 아니다. 그림만 모드에서는 링 그래픽과 다른 글자·에셋을 필터 처리 뒤에 선명하게 합성한다. 전부 모드는 합성된 링 장식·글자·에셋까지 필터 처리한다. 대상 선택은 docs/censor-resize-scope.md 참조. 필터끼리와 일반 items끼리의 순서는 유지한다. 저장/Undo/레이어순서 변경 후에도 설정과 기하로 다시 계산한다.

필터에 해당 링이 없으면 기존 출력 경로를 그대로 쓴다. 있을 때만 기존 표본 이미지와 별도로 출력/alpha 마스크 Canvas를 만들며 각각 524,288픽셀·변 1,024px 이하로 제한한다. alpha 처리는 제한된 크기의 ImageData에서만 수행하고 임시 Canvas는 1×1로 해제한다. 전체 페이지 복사·복원본 캐시·프로젝트 전체 복제를 추가하지 않는다. 큰 4K 영역은 계산 해상도 상한 때문에 링 경계가 다소 부드러워질 수 있다. 모든 기기의 메모리/속도를 보장하지 않는다.

표지판의 불투명도는 겹친 장식 전체에 한 번 적용한다. 보통은 벡터/텍스트로 직접 그리고 반투명은 작은 임시 래스터, 뒤틀기는 기존 유한 stickerWarpCache를 이용한다. 새 무제한 이미지 캐시를 만들지 않는다.
