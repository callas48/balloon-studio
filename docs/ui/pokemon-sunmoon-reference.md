# 포켓몬 썬·문 / 배틀 UI 참고 검토 (2026-10-25)

사용자 첨부 7060–7064를 기준으로 code-native Canvas UI를 재구성했다. 첨부 자체·캐릭터·배경·워터마크는 앱에 포함하지 않았다.

## 첨부와 구현
- 7060/7063: 파란 이름표, 옅은 삼각 문양의 흰 곡선 대화창, 붉은 ▼. gamePreset8 named.
- 7061: 이름표 없는 흰 대화창과 위쪽 예/아니요 선택창. gamePreset8 choice, 문구와 선택 표시 편집.
- 7062: 검은 안내창과 흰 대사/붉은 ▼. gamePreset8 dark.
- 7064: 자주색 도트 HP 패널, 타입 배지, 붉은 테두리의 하단 2×2 행동 메뉴. gamePreset9 retro, 싱글/더블 선택. 이 첨부를 썬·문 본편 배틀 화면이라고 표기하지 않는다.

## 자체 검색으로 확인한 차이
1. [공식 지가르데 소개](https://www.pokemon.co.jp/ex/sun_moon/story/160906_02.html)의 img_05.png: 파란 이름표/흰 삼각 문양/붉은 ▼ 대화창 확인. 일본어 스크린샷은 단어 강조색도 포함하지만 이번 범위는 창 서식/문구 편집이다.
2. [공식 Z기술 상세](https://www.pokemon.co.jp/ex/sun_moon/fight/161114_02.html) 및 공식 common/images/fight/161114_02/thumb.png: 본편 배틀은 청록색 붓자국 모양 HP 패널과 푸른 그라데이션 메시지창. 참고 첨부7064의 도트 배틀과 구분해 gamePreset9 sunmoon HUD 카드를 별도로 제공한다. 공식 자료는 개발중 화면/일부 가공 안내가 있으며 전체 UI의 모든 상황을 망라한 조사로 표현하지 않는다.
3. [Serebii 공개 스크린샷 모음](https://www.serebii.net/sunmoon/pics.shtml)도 비교 검색했다. 로토무 전용/강조 대화 등은 이번 조사에서 재현 근거가 충분한 추가 범용 창으로 확정하지 않았다.

## 편집과 제한
- 대화4종(이름표/일반/선택/검은 안내), 배틀3종(첨부형 싱글/더블, 본편 청록HUD). 기존골드/마스터즈보존.
- 각 창은 문구·표시·배경을 편집할 수 있는 이미지용 UI다. 배틀을 실행하거나 선택지가 이야기 분기를 실행하는 게임은 아니다.
- 배틀 HP는 현재/최대 값의 비율로 길이/색을 그린다. 이름/레벨/성별/타입/행동메뉴/선택표시/시간을 독립 편집한다. 공식 청록HUD에서 행동메뉴는 기본 숨김, 선택적으로 켜면 편집용 배치다.
- 기존 PNG/원본장 내보내기와 전용 UI 투명 PNG를 사용한다. 저장/복원·썸네일·복제는 기존 gameui 경로다.
- tests/pokemon-sunmoon.cjs가 실제 공통 핸들러와 Canvas를 검사한다. 실제 브라우저/모바일 터치 검증은 별도이며 미실시.
